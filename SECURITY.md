# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it privately rather than opening a public issue on GitHub.

The project is currently maintained by its author. When reporting a potential vulnerability, please include:

- A description of the issue.
- Steps to reproduce or a proof of concept.
- Any relevant context regarding potential impact.

Please allow reasonable time for the report to be reviewed and addressed before disclosing any details publicly.
